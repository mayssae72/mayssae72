## 🚀 Featured Projects

### 🎯 [ERP Lead Intelligence Engine](https://github.com/mayssae72/erp-lead-engine)
AI-powered lead generation system that scrapes Moroccan companies, enriches their profiles with web signals, and uses a local LLM (Ollama) to score their ERP need probability — delivering a prioritized prospect list with auto-generated email drafts to the sales team.

`Python` `BeautifulSoup` `Ollama` `Flask` `SQLite` `Pandas`

---

### 📦 [Stock Optimizer](https://github.com/mayssae72/stock-optimizer)
End-to-end ML pipeline for ERP stock management — demand forecasting (XGBoost, LightGBM, Prophet, Chronos), ABC classification, safety stock optimization, EOQ calculation, and supplier recommendation scoring. Includes a full Flask dashboard.

`Python` `XGBoost` `LightGBM` `Prophet` `Flask` `MySQL` `Scikit-learn`

---

### 🗣️ [MAGREBFEEL](https://github.com/mayssae72/MAGREBFEEL)
Web application that automatically detects Maghrebi dialects (Moroccan, Algerian, Tunisian) and performs sentiment analysis — built with Streamlit and NLP models fine-tuned on Arabic dialect data.

`Python` `NLP` `Streamlit` `HuggingFace` `Sentiment Analysis`

---

### 🧾 [Invoice Data Extraction](https://github.com/mayssae72/extraction-factures)
Automated invoice extraction system supporting PDF and image formats using Mistral 7B LLM — with an editable interface before database registration.

`Python` `LLM` `Mistral 7B` `PDF Processing` `OCR`
